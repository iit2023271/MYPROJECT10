# Parallax Effect Demo

Colored dots drift across the screen in response to your mouse movement — a simple mouse parallax effect.


## Features

- Five colored dots at different positions on a purple background
- Each dot moves at a different depth based on its `value` attribute
- Movement is driven by the mouse position, with a smooth transform

## Tech Stack

- HTML
- CSS
- JavaScript (single self-contained file)

## How to Run

Just open `index.html` in any browser and move your mouse around. No build step, no server needed.

```bash
# or serve it locally
python3 -m http.server
# then open http://localhost:8000
```
